## Round 9: running Assembly or Fortran interactively in the browser

- **Question:** if the interactive parts are written in Assembly or Fortran, how do they run in a static page?
- **Answer:**
  - WebAssembly, compiled during the Actions build and run in the visitor's browser.
  - **Fortran:** LFortran's Wasm backend, LLVM Flang with Emscripten, or f2c with Emscripten for FORTRAN 77.
  - **Assembly:** NASM building DOS programs run in js-dos (or v86 for a full PC); hand-written WebAssembly text; or an assembler and emulator in the page (RISC-V or 6502).
  - Limits: multithreaded Wasm needs the `coi-serviceworker` workaround on GitHub Pages; emulators add a few MB.
  - Suggested two proof-of-concept demos: a Fortran heat-equation kernel with a slider and chart, and a NASM Mode 13h program in js-dos.
